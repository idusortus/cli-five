# cli-five — Project Vision

## One-line
Code Like I'm Five — scaffold a 5-agent AI team (GitHub Copilot or OpenCode) into any repo.

## Goal
Give any repository a working, autonomous 5-agent AI team — Orchestrator routing to
Planner, Coder, Designer, and Reviewer — for **GitHub Copilot or OpenCode**, plus optional
integrations (CodeGraph, OpenSpec, jev). Installation is idempotent and non-destructive:
re-running never clobbers local edits.

## Stack
- Node (ESM JavaScript), no build step

## Frameworks / Key Libraries
- `kleur` (terminal color), `prompts` (interactive interview), `skills` (skill discovery), `yaml`
- Node's built-in test runner (`node --test`) and ESLint 10 (flat config)

## Quickstart
```bash
npx cli-five init                 # minimal scaffold (5 agents + required tooling)
npx cli-five init --full-interview
npx cli-five doctor               # validate an existing setup
npx cli-five list-addons
npx cli-five add codegraph        # optional integrations

npm ci && npm run lint && npm test # develop this repo
```

## Hard Constraints
None declared.

## Out of Scope
- **Not a runtime or workflow engine.** Scaffolded repos do not depend on `cli-five`; there is no daemon, no issue-polling loop, and no large slash-command surface.
- **No extraction of the Jev tier-router into a separate package.** It stays in-package and runtime opt-in; extraction is revisited only if it earns it.
- **No new runtime dependency** in the CLI, and the copied Jev plugin stays dependency-free.
- Google Antigravity / AGY CLI support is planned but not implemented.

## Success Criteria
- `npx cli-five init` scaffolds a working 5-agent team for Copilot or OpenCode, and `doctor` reports all required files present.
- All five agents register and run (OpenCode: `opencode debug agents`; a live Orchestrator → Planner delegation returns the expected reply).
- Re-running `init` / `add` is idempotent and non-destructive (create-once user files, add-only `opencode.json` merge).
- `npm test` and `npm run lint` pass on Node 20/22/24 in CI.
